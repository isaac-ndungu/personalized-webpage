# Personalized Webpage Project

This project is an interactive personalized webpage built using HTMl, JavaScript, and CSS. The webpage collects a users age and name, stores it in localStorage, and displays personalized content.

## Contributor

Isaac Ndungu

## Project Brief 
 The main objective of this project is to collect user information (`name` and `age`), process it using JavaScript logic, store it using `localStorage`, and display meaningful personalized feedback.

key Features of the project include:

* Displaying personalized greeting - The application retrieves user information from localStorage and dynamically generates a greeting message using template literals
* calculating the users age in months - The application uses a function to calculate the user's age in months.
* conditional age verification logic - The application uses an `if...else` statement to determine whether the user is legible for adult content.
* Displaying motivational quote 5 times - The application uses a `for` loop to render a motivational quote five times on the webpage.
* persistent user experience with localStorage - The application persists across page reloads.
